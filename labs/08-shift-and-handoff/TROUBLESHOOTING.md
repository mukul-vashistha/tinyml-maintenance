# Troubleshooting

Do not compare only ROC-AUC across shifts. Check the class balance, average precision, threshold, confusion matrix, and action behavior.

A new threshold chosen from the unseen test set would leak final evaluation into policy design. Create new validation evidence before changing the policy.

The extension challenge asks for one capability. A monitoring service, retraining platform, dashboard, and new model in one patch cannot be reviewed well in 90 minutes.
