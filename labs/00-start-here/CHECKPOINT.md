# Checkpoint

If a term is unfamiliar, ask the coach to explain it with the machine example before answering.

1. What does the system estimate at each six-hour observation?
2. Why is predicting a possible failure in advance useful to an operator?
3. How is the prediction different from an action such as "schedule inspection"?
4. Which file states the operating problem?
5. Which saved result shows that the generated labels include real positive cases?

Short answers are enough when they are in your own words and tied to repository evidence.
